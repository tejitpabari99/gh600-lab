# Reliable Calculator

A production-ready Python calculator library.

## Capabilities

- Supports division and percentage calculations.
- Validates all inputs and returns clear errors for invalid values.
- Handles division by zero safely.
- Has complete automated test coverage.
- Every pull request runs tests, linting, and security scanning.
- Supports Python 3.9 and later.

## Usage

```python
from calculator import percentage

print(percentage(25, 100))
